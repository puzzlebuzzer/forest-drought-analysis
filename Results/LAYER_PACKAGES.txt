Layer Packages
==============
The following ArcGIS layer packages (.lpkx) will be generated in this directory
once the _3_24 cache build is complete.  Files are excluded from version control
due to file size.  Store and share via network drive, external storage, or ArcGIS Online.

  TNC_Appalachian_Indices.lpkx
    Monthly max composites for NDVI, NDMI, EVI — Sentinel-2
    Covers north (GWNF) and south (Smoky) AOIs, 2017–present

  TNC_Appalachian_Indices_Monthly.lpkx
    Full monthly layer stack — Sentinel-2
    Covers north (GWNF) and south (Smoky) AOIs, 2017–present

These packages will be generated from the GWNF_cache_3_24 / Smoky_cache_3_24
index caches using the compositing scripts in Analysis/.

Cache improvements in _3_24 vs prior cache (_3_4):
  - AOI polygon masking (replaces bounding box)
  - Cloud-only SCL exclusion: classes 8, 9, 10, 11 (replaces SCL==4 vegetation filter)
  - PB04.00 harmonization applied at build time
  - SCL and QA_PIXEL saved to disk alongside index TIFs
  - Snow fraction recorded per scene in manifests

See Results_cache1/LAYER_PACKAGES.txt for packages generated from the _3_4 cache.
