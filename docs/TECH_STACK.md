# Tech Stack

This document summarizes the technology stack used by the Appalachian terrain-vegetation project.

## Core Stack

- Python
- Bash
- Git
- GitHub
- WSL / Linux shell
- Markdown

## Remote Data And Platform Services

- Microsoft Planetary Computer
- STAC API
- Sentinel-2 L2A
- Landsat Collection 2 Level 2

## Python Libraries

- numpy
- pandas
- matplotlib
- rasterio
- geopandas
- shapely
- pystac-client
- planetary-computer

## GIS And Presentation Tools

- ArcGIS Pro
- Mermaid
- Obsidian

## Data Formats

- GeoTIFF
- CSV
- JSON
- YAML
- Shapefile
- PNG
- LPKX

## Project Processing Stack

- Scene-level raster caches
- AOI-aligned raster grids
- Trait rasters: ecozone, elevation, forest, terrain/aspect
- Monthly max composites
- Annual max composites
- Anomaly rasters
- Ecozone summary and comparison analyses

## Scientific / Analysis Vocabulary

- NDVI
- NDMI
- EVI
- Wet / neutral / dry year classification
- Ecozone stratification
- Onset / progression / recovery analysis

## Short Reusable Summary

The project stack is:

Python, Bash, Git/GitHub, WSL, Microsoft Planetary Computer/STAC, rasterio/geopandas/numpy/pandas/matplotlib, ArcGIS Pro, and geospatial data products built around GeoTIFF, CSV, JSON, YAML, PNG, and Shapefile workflows.
